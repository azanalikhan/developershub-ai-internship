Assignments completed during an AI/ML Engineering internship at **DevelopersHub Corporation**, covering classical ML, deep learning, and LLM-based applications across two stages.

---

## Overview

This repository contains two batches of hands-on tasks completed over the course of the internship, progressing from foundational ML workflows to advanced deep learning and LLM-powered systems.

| Stage | Folder | Focus |
|---|---|---|
| First Batch | `Assignment 1` | Classical ML, data exploration, and chatbot prototyping |
| Advanced | `Assignment 2` | Deep learning, retrieval-augmented generation, and LLM-based tasks |

---

## Assignment 1 — Foundational Tasks

Six Jupyter notebook tasks covering core data science and ML workflows:

- **Iris EDA** — exploratory data analysis on the classic Iris dataset
- **Stock Prediction** — time-series forecasting using live data via `yfinance`
- **Heart Disease Classification** — classification model trained on an OpenML dataset
- **Health Chatbot** — a Groq-powered chatbot using `llama-3.3-70b-versatile`
- **Mental Health Chatbot** — a chatbot with a fine-tuning demonstration
- **California Housing Price Prediction** — regression model on the California Housing dataset

## Assignment 2 — Advanced Tasks

Five advanced tasks, debugged end-to-end on a Windows/CPU environment:

- **BERT Classifier** — text classification using a fine-tuned BERT model
- **Scikit-learn Pipeline** — a full preprocessing + modeling pipeline
- **Multimodal CNN** — a convolutional model handling multiple input types
- **RAG Chatbot** — retrieval-augmented generation using LangChain and FAISS
- **LLM Zero-shot/Few-shot Tagging** — tagging tasks using an LLM without (and with) few-shot examples
